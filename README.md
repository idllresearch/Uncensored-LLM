# [ACM IMC '26] Characterizing the Ecosystem of Open-Source Uncensored Large Language Models: Supply Chain, Governance, and Risks

[![DOI](https://img.shields.io/badge/DOI-10.1145/3777912.3839799-009682.svg)](https://dl.acm.org/doi/10.1145/3777912.3839799)
[![arXiv](https://img.shields.io/badge/arXiv-2508.12622-b31b1b.svg)](https://arxiv.org/abs/2508.12622)
[![GitHub](https://img.shields.io/badge/github-Repo-blue?logo=github)](https://github.com/idllresearch/Uncensored-LLM/)

This repository hosts the research artifacts for [the comprehensive measurement study](https://dl.acm.org/doi/10.1145/3777912.3839799) of open-source uncensored LLMs and their associated ecosystem, published at [the 26th ACM Internet Measurement Conference (IMC '26)](https://conferences.sigcomm.org/imc/2026/).

## Complete List of Open-Source Uncensored LLMs
[![UncensoredLLMList](https://img.shields.io/badge/HuggingFace-UncensoredLLMList-yellow?logo=huggingface)](https://huggingface.co/datasets/idllresearch/UncensoredLLMList)
[![UncensoredLLMList](https://img.shields.io/badge/GitHub-UncensoredLLMList-87CEFA?logo=github)](https://github.com/idllresearch/Uncensored-LLM/blob/main/list/uncensored_LLMs.json)

This dataset contains **22,096 open-source uncensored LLMs**, collected from **five model hubs: Hugging Face, ModelScope, Kaggle, OpenCSG, and John Snow Labs**.
The identification is based on their publicly available model metadata.


## UncensoredBench -- A QA Benchmark for Uncensored LLMs
[![UncensoredBench](https://img.shields.io/badge/HuggingFace-UncensoredBench-yellow?logo=huggingface)](https://huggingface.co/datasets/idllresearch/UncensoredBench)
[![UncensoredBench](https://img.shields.io/badge/GitHub-UncensoredBench-87CEFA?logo=github)](https://github.com/idllresearch/Uncensored-LLM/blob/main/list/UncensoredBench_QA.json)

This dataset contains **6,650 question-answer (QA) pairs** generated by **105 uncensored LLMs** and 28 non-uncensored LLMs in response to 50 harmful prompts.
