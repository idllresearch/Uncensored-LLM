You are given up to four inputs from a model repository: model ID, repository URL or identifier, model card text (README.md), and configuration text (config.json).
Your job is to determine whether the repository is specifically a **text-generation large language model (LLM)**. This requires that the model is BOTH: (1) a large language model, AND (2) designed for text generation.


## Inputs

You may receive:
- MODEL_ID
- REPO_URL_OR_IDENTIFIER
- MODEL_CARD_TEXT (README.md)
- CONFIGURATION_TEXT (config.json)
Some fields may be missing. Use whatever is available.

## Core definition

A model is LLM = true ONLY if:
it is a language model (not vision/audio/etc.), AND it is used for text generation (not only encoding, embedding, or classification)

## Classification policy

Classify as **LLM (true)** only when there is strong and consistent evidence of BOTH Large language model properties AND Text generation capability
### Positive evidence

- pipeline tags like: - text-generation - text2text-generation - conversational
- tags: - llm, causal-lm
- architectures (generation-oriented LMs):- AutoModelForCausalLM - LlamaForCausalLM - MistralForCausalLM - Qwen2ForCausalLM - PhiForCausalLM - GPT2LMHeadModel - FalconForCausalLM - BloomForCausalLM - MPTForCausalLM - GemmaForCausalLM
- README phrases: - "text generation" - "large language model" / "LLM" - "chat model" - "instruction-tuned" - "causal language model" - "assistant" - "prompt" / "response"

## Not LLM (negative cases)

Classify as false if ANY of the following holds:

- the model is not a language model (e.g., vision/audio/video)
- the model is language-related but NOT generative (e.g., embedding, encoder-only, classifier)
- the evidence does not clearly support BOTH ``LLM'' AND ``text generation''
### Negative evidence

- pipeline tags: - image-classification - text-to-image - image-generation - automatic-speech-recognition - text-to-speech - audio-classification - video-classification
- architectures: - UNet* - StableDiffusion* - CLIPVisionModel - WhisperForConditionalGeneration - Wav2Vec2* - SpeechT5* - ViT* - Detr* - Sam* - VideoMAE*
- README phrases: - "diffusion" - "text-to-image" - "speech recognition" - "voice cloning" - "audio model" - "vision encoder" - "embedding model" - "sentence embedding" - "reranker"

## Decision rules

Return true ONLY if there is clear evidence that the model is BOTH:
- a large language model, AND
- used for text generation.
Return false If only one condition is satisfied, OR the model is non-text, OR the evidence is weak, mixed, or unclear.

## Hard constraints

- Output must be valid JSON only
- No markdown
- No explanation
- No extra keys
- No trailing commas

{
  ``repo_url_or_identifier'': ``<repo_url_or_identifier>'',

  }
