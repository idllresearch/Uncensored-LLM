We define a model as a text-generation large language model (LLM) if and only if it satisfies two conditions: (C1) the model is a large language model operating on natural language, and (C2) the model is designed for text generation. Annotators are instructed to assign a positive label (LLM=True) only when there is clear and consistent evidence supporting both conditions; otherwise, the model is labeled as False.

To determine whether a model satisfies C1, annotators consider explicit descriptions such as ``large language model'', ``LLM'', or ``causal language model'', as well as known large language model architectures including GPT-style models, LLaMA, Mistral, Qwen, Phi, Falcon, Bloom, MPT, and Gemma. Architectures such as ``AutoModelForCausalLM'' and other ``*ForCausalLM'' variants are also treated as strong evidence. In addition, models with tags such as text-generation, text2text-generation, or conversational are considered likely large language models.

To determine whether a model satisfies C2, annotators look for explicit evidence of text generation capability, including descriptions such as ``text generation'', ``chat model'', ``assistant'', ``instruction-tuned'', or prompt-response behavior. Supporting evidence also includes pipeline tags such as ``text-generation'' and ``text2text-generation'', as well as generation-oriented architectures including ``*ForCausalLM'' and ``*ForConditionalGeneration''. However, annotators are instructed not to rely solely on architecture names when usage is unclear; evidence from model descriptions takes precedence.

A model must be labeled as False if it is not a large language model (e.g., models primarily designed for vision, audio, video, or speech tasks, including diffusion or text-to-image systems), or if it is not generative (e.g., embedding models, sentence transformers, rerankers, or classifiers). Also, if the available evidence is insufficient, ambiguous, or conflicting with respect to either condition, annotators must assign a negative label following a conservative strategy.

When conflicting signals arise, annotators resolve them by prioritizing (in order) the model card or README description, pipeline tags, model architecture, and finally the model name or identifier. For multimodal models, annotators assign a positive label only if text generation is a core capability; otherwise, the model is labeled as False.

Overall, annotators follow a conservative and evidence-based principle: a model is labeled as a text-generation LLM only when both language modeling and generation capabilities are clearly supported by strong and consistent evidence.
